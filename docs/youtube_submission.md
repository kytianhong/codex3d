Codex3D: Natural-Language Blender Creation with Safe Restore | OpenAI Build Week

## Description

Codex3D is a local-first creative 3D agent that lets designers and Blender beginners create, refine, validate, and safely restore scenes through ordinary language.

In this demo, Codex with GPT-5.6 turns visual intent into allowlisted MCP tools. An authenticated localhost bridge executes structured actions on Blender's main thread, then returns compact scene inspection and visual validation for the next feedback turn. Stable object UUIDs and fingerprinted snapshots make rejected creative directions reversible.

Highlights:
- Natural language to structured MCP tools to Blender
- Progressive geometry, materials, lighting, camera, and animation
- Visual follow-up without breaking the approved six-curve structure
- Rejected edit followed by fingerprint-verified snapshot restore
- Validated PNG, H.264 MP4, and versioned Blender checkpoint
- No arbitrary Python or shell MCP tool

Repository: https://github.com/kytianhong/codex3d
Release: https://github.com/kytianhong/codex3d/releases/tag/hackathon-v0.1.0
