# MVP Demo Prompts

These prompts describe the kind of creative loop Codex3D should eventually support.

## Single Object

```text
Create a small wooden stool for a cozy cafe. Make the seat round and the legs slightly angled.
```

Follow-up:

```text
Make it warmer and more handmade, but keep the height the same.
```

## Room Scene

```text
Create a tiny 1960s design studio with a desk, chair, lamp, papers, window, and warm evening light.
```

Follow-up:

```text
Move the lamp closer to the desk and make the chair less modern. Do not move the camera.
```

## Undo Direction

```text
I liked the previous layout better, but keep the new lighting.
```
